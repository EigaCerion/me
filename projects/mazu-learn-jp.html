About the project

Learning Japanese, from zero to JLPT N4, in the browser.

Mazu Learn JP is a self-contained web app that takes a learner from Hiragana and Katakana all the way through JLPT N5 and N4 — grammar patterns, vocabulary, kanji, reading comprehension, and listening practice with text-to-speech. It's built as plain HTML, CSS, and JavaScript, with no framework and no backend: all 240 kanji flashcards, grammar notes, and audio-driven listening exercises run entirely client-side.

My contribution

Helping push the front end forward.

I contributed to the front end of the app, working alongside the original author to help refine the experience. It's a small piece of a larger project built and led by a friend — I'm listing it here because it's real, collaborative work, not to claim sole credit for it.

What's next

From web app to mobile app.

The project is still under active development. The next planned step is extending it from a web-based tool into a proper mobile app, so the same lessons and flashcards work offline, on the go.
